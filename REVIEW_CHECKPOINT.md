## Revisions made

| Finding | Revision |
| --- | --- |
| TIFF reading could follow references to external OME files. | Disabled multi-file reading and rejected external OME image/metadata references before enumerating series. Added a regression test. |
| TIFF generation included a changing OME UUID. | Fixed the demo UUID and verified identical generated bytes on repeated calls in the tested environment. |
| Demo ground-truth masks and generation details were discarded. | Retained masks and recorded generator version, seed, channel roles, signal levels, and deliberate saturation. |
| Synthetic source status could enable DNA rules on the marker channel. | Restricted automatic demo DNA suggestions to the generated DNA channel. The marker channel remains uncertain in DNA mode. |
| Source integrity was checked on reopening but not before measurement. | Added SHA-256 verification before preview and measurement, plus a tampering test. |
| Object-count checks occurred after narrowing label integers. | Check the full label array before converting it to uint16. |
| SQLite connections relied on implicit cleanup. | Added deterministic connection closure and retained transaction boundaries. |
| Worker threads had no application shutdown path. | Added FastAPI lifespan cleanup and cancellation before executor shutdown. |
| A synthetic reference could theoretically be zero. | Added a positive-reference check before DNA normalization. |
| A deprecated scikit-image property was used. | Switched to `image_intensity`. |
| CSV columns depended on matching positional lists. | Replaced the mapping with named fields and checked CSV/JSON consistency and escaping. |
| Runtime and dependency versions were not recorded. | Added a dependency lockfile and declared Python 3.12 as the tested baseline. |
| Code was difficult to scan in compressed expressions. | Formatted Python sources and added explicit lint configuration. |

## Checks

The backend suite contains **24 passing cases**, including parametrized channel/plane validation. It checks:

- Deterministic fixture pixels, retained ground truth, metadata, and duplicate imports.
- Explicit series/T/Z/channel selection, unsupported axes, ordinary-TIFF confirmation, resource limits, corrupt imports, and external OME references.
- Nuclear masks, raw measurements, saturation flags, real-image uncertainty, and capability-specific labels.
- Original suggestions surviving correction and undo; exclusions requiring a reason.
- Stable identity across reruns and preservation of earlier reviewed records.
- Failed and cancelled jobs leaving no committed partial run.
- Durable session reopening after a service restart and detection of altered source bytes.
- Matching CSV/JSON row counts, quoted text, line breaks, and spreadsheet-formula escaping.
- Rejection of mismatched/synthetic calibrations on real sources and rejection of external browser origins.

Ruff lint and formatting checks pass. `pip check` reports no broken requirements. One upstream test-client deprecation warning remains: Starlette recommends its newer `httpx2` transport. The current `httpx` test transport still passes; this warning is not hidden.

An additional loopback-server smoke check exercises health, API documentation, a generated demo, PNG preview, an actual analysis job, and CSV export. Its final result is recorded in `docs/validation/server-smoke.json`. The smoke server is stopped after verification.

These checks validate software behavior on generated images and small constructed TIFFs. No independent labeled real microscopy dataset has been evaluated. No browser tests, contrast checks, keyboard-flow checks, or production frontend build have been run because the interface is not implemented yet.
