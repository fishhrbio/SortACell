# SortACell wiki

SortACell is a local workspace for reviewing segmented nuclei in a selected 2D microscopy plane. Start with the generated demo, then try a representative TIFF file and compare masks with the source image before interpreting measurements.

- [Getting started](Getting-Started.md) covers setup, supported images, and the demo walkthrough.
- [Review workflow](Review-Workflow.md) covers channel mapping, capabilities, viewer navigation, quality flags, and corrections.
- [Methods and limitations](Methods-and-Limitations.md) covers segmentation, source measurements, calibration, and evaluation.
- [Sessions and exports](Sessions-and-Exports.md) covers workspace data, backups, identity, and CSV/JSON.
- [Development](Development.md) covers the architecture, tests, and troubleshooting.

Version 0.1.0 includes the local import-to-export workflow. Biological suggestions remain unvalidated on independently labeled real microscopy data.
